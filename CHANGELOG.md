# Changelog

## 0.1.0

Initial Penny memory plugin for OpenClaw `2026.10.1-beta.2`.

- Private native search and caller-bound snapshot retrieval.
- Independent OAuth login with PKCE, token rotation, and private local storage.
- Profile, search, and explicit private-save tools.
- Optional recall and selected-fact capture, plus a tool-based compaction checkpoint.
- Access checks for owner sessions and private-only save receipts.
